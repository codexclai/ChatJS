# Support

ChatJS is currently in repository bootstrap and pre-implementation.

## Where to ask

- Use GitHub Issues for reproducible bugs, feature requests, and documentation suggestions.
- Use the private security reporting path described in SECURITY.md for vulnerabilities.
- Read docs/CONTINUATION.md for project workflow and docs/TODO.md for current priorities.

## Before opening an issue

Include:
- Node.js version and operating system;
- ChatJS package version or commit SHA;
- minimal reproduction and expected/actual behavior;
- relevant sanitized error output;
- whether the problem reproduces on the supported Node.js LTS matrix.

Do not include API keys, passwords, cookies, personal information, private messages, APK files, or proprietary application assets.

## Support boundaries

ChatJS is an independent project. It cannot provide OpenAI account support, change account access or subscriptions, guarantee access to private ChatGPT services, or promise compatibility with unsupported interfaces.
